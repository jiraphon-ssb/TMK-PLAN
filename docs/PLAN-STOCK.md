# PLAN — ระบบสต็อก เฟส 1: "สต็อกตั้งต้น + นับสต็อก" (PART 112)

> ขอบเขตที่ user เคาะ (24 ส.ค. 2569): **เอาแค่ นับสต็อก + สต็อกตั้งต้น ก่อน** ·
> คุมเฉพาะ **ลายที่ขายจริง** (บางลายเลิกขาย/ของหมดไปแล้ว) · **มีไฟล์ Excel อยู่แล้ว** สำหรับตั้งต้น

## เป้าหมายเฟสนี้
1. เอาสต็อกที่มีอยู่ในไฟล์ Excel เข้าระบบให้ครบ (ครั้งเดียว)
2. นับสต็อกจริงซ้ำได้ทุกเดือน โดยไม่ต้องแก้ไฟล์นอกระบบอีก
3. เห็น "เหลือเท่าไร" ต่อ ลาย × สี × ไซซ์ แบบสด (หักของที่ขายไปหลังวันนับให้อัตโนมัติ)

**ยังไม่ทำในเฟสนี้** (ตามที่ user สั่ง): รับเข้าจากโรงงาน · ใบสั่งผลิต · ต้นทุน/มูลค่าสต็อก · เตือนของใกล้หมด · สลีป

## หลักการคิดยอดคงเหลือ (สำคัญ — เป็นรากของทุกเฟสถัดไป)
```
คงเหลือ(SKU) = จำนวนที่นับได้ครั้งล่าสุด − จำนวนที่ขายไปหลังวันที่นับนั้น
```
- "การนับ" = จุดอ้างอิง (anchor) แบบ **absolute** ณ วันหนึ่ง — ไม่ใช่ยอดบวก/ลบ
- ของออก **ไม่เก็บลงตาราง** — คิดสดจาก `tmk_mp_skus` (ตัดใบยกเลิก) เหมือนที่ยอดขายทั้งระบบทำ
  → ยกเลิกใบเสร็จ = ของกลับเข้าสต็อกเองทันที ไม่มีเลขค้าง (บทเรียน PART 90)
- นับใหม่ทีไร = anchor ใหม่ ทับของเก่า (ไม่ต้องล้างข้อมูล ไม่ต้องคำนวณย้อน)
- สต็อกตั้งต้นจาก Excel = "การนับครั้งที่ 0" (kind='open') → ใช้กลไกเดียวกันเป๊ะ

## ข้อมูล
ตารางใหม่ 1 ตัว — `tmk_stock_counts` (1 แถว = 1 SKU ใน 1 รอบนับ)
| คอลัมน์ | ความหมาย |
|---|---|
| id | `<session>::<design>::<color>::<size>` |
| session_id | รอบนับ (import 1 ครั้ง / นับ 1 ลาย = 1 session) |
| count_date | วันที่ยึดเป็น anchor |
| design · color · size | คีย์ SKU (normalize แล้ว) |
| product_code | รหัสลาย (ถ้าจับคู่ได้) |
| qty | จำนวนที่นับได้ |
| kind | `open` (ตั้งต้นจาก Excel) / `count` (นับรอบปกติ) |
| note · created_by · created_at | หลักฐาน |

- ไม่แตะตารางเดิม · ไม่มีข้อมูลเงิน
- RLS ตาม convention เดิม (authenticated) · idempotent + VERIFY + ROLLBACK

## หน้าจอ (เพิ่มหน้าเดียวใต้เมนู "ยอดขาย" → **สต็อก**)
1. **ตารางคงเหลือ** — ต่อลาย: เหลือรวม · จำนวนสีที่มีของ · ขายไปแล้วหลังนับ · วันที่นับล่าสุด → กดลายเพื่อกางกริด สี × ไซซ์
2. **ปุ่ม "นับสต็อก"** — เลือกลาย → กริด สี × ไซซ์ (พรีฟิลด้วยยอดคงเหลือปัจจุบัน) → กรอกจำนวนจริง → บันทึก = สร้าง anchor ใหม่
   - เห็น "ระบบคิดว่าเหลือ X · นับได้ Y · ต่าง Z" ทันทีระหว่างกรอก
3. **นำเข้าสต็อกตั้งต้น (แอดมิน)** — อัปโหลด Excel/CSV หรือวางจากคลิปบอร์ด → ตรวจ/จับคู่ลาย → ยืนยัน
   - รองรับ 2 รูปแบบไฟล์: (ก) คอลัมน์ยาว `ลาย · สี · ไซซ์ · จำนวน` (ข) ตารางไขว้ แถว=สี คอลัมน์=ไซซ์ (มีหัวบล็อกเป็นชื่อลาย)
   - โชว์ "จับคู่ไม่ได้ N รายการ" พร้อมเหตุผล ก่อนบันทึก (ไม่บันทึกเงียบ)

## ลายที่คุม = "ลายที่ขายจริง"
- รายชื่อลายในหน้าสต็อก derive จาก `tmk_mp_skus` (เคยขายจริง) — เลือกช่วงได้ (90 วัน / 180 วัน / ทั้งหมด)
- ลายที่ไม่เคยขายเลยจะไม่รก แต่ยัง import/นับได้ถ้าไฟล์มี (ขึ้นกลุ่ม "นอกรายการขาย")
